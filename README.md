# VOID TREE — дерево пустоты

Неоновая idle-игра в духе *Void Platform*: дерево узлов лежит в перспективе на тёмной
платформе, валюты капают сами — кликать не нужно. Один файл, без зависимостей и без интернета.

Открыть: двойной клик по `index.html` (или `start index.html`).

## Версия
Текущая версия показана внизу левой панели и в ⚙ (Версия + дата сборки). Сейчас **v0.5.2**.

## Валюты и цикл
- **Void** (фиолетовый) — базовая валюта, капает с ядра.
- **Light ✦** (золотой) — открывается узлом «ЛУЧ» на золотой ветке; золотые узлы стоят свет и множат пустоту.
- **BIG BANG** — престиж: сжечь собранное дерево и получить **×2 ко всему навсегда**; за каждый прогон дают **Everlasting ⚡**.
- **Everlasting ⚡** (синяя ветка справа) — постоянные уровни: множители и **авто-покупатели** узлов. Не сгорает при Big Bang.
- **Авто-сброс** — сам жмёт Big Bang, когда дерево собрано.
- Оффлайн-доход до 12 часов, автосейв в `localStorage`.

## Узлы
- Открываются по цепочке: узел доступен, когда куплен родитель.
- У узлов с бейджем `2/5` есть уровни: каждый следующий уровень дороже (×`costMul`), эффект суммируется.
- В ⚙ есть режим **«Покупка всех уровней»** — клик по узлу выкупает сразу столько уровней, на сколько хватает валюты.
- `ЗАКРЫТО` — родитель не куплен, `КУПЛЕНО`/`МАКС` — выкуплено.

## Управление
- Мышь: тянуть — панорама, колесо — зум, двойной клик — сброс вида.
- Кнопка ⌖ — камера к следующему доступному узлу.

## Технически
`index.html` — вся игра: CSS-неон и clip-path формы узлов, SVG-связи на «полу»,
фон на CSS-градиентах и плавающих кляксах, WebAudio-звуки, псевдо-3D раскладка рядов (`rowY` / `rowS`),
сейв в `localStorage` (`voidtree.save.v4`, миграция со старых версий).

## Экономика
25 узлов (вайт + 4 золотых + 5 вечных), у большинства 10–20 уровней — всего ~370 покупок за прогон.
Полностью прокачанное дерево упирается в **1e308** (дальше показывается `1.00e308`, всё клампится).
Большие числа: K…Vg, дальше научная запись вида `1.23e120`.
